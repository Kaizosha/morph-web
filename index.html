01 / ABOUT

About

Morph is an iPhone- and iPad-first Safari extension for changing the webpage currently open in Safari. Describe the result you want, inspect the draft, optionally ask the agent to improve it, apply it locally, and undo it as one transaction.

  1. Open a webpage in Safari and invoke Morph.
  2. Describe the change you want in plain language.
  3. Inspect the draft and refine it when needed.
  4. Apply the local edit or cancel it; undo remains available.

02 / EDITING AUTHORITY

Three deliberate modes

Safe Mode
Targeted styling, hide or show changes, and visible-text edits through a small validated operation set.
Agent Mode
Reconstructs the local page structure and layout through bounded declarative operations. Drafts can be refined across one to three configured passes, then applied or reversed as one transaction. Morph does not execute model-generated JavaScript.
Source Mode
A separate, opt-in workflow for websites you own. A trusted paired Mac lets Codex edit an explicitly allowlisted Git repository; you review, commit, and deploy the resulting local changes yourself.

03 / PROVIDERS

Your models, your order

Morph tries enabled providers in the priority you choose. Availability depends on your device and configuration.

Codex Bridge
Uses the Codex account already authenticated on a trusted paired Mac and supports Agent and Source workflows.
Apple Intelligence
Uses Apple's on-device Foundation Models when the device and system model are supported, enabled, and ready.
Local model
Connects to Ollama, LM Studio, or another OpenAI-compatible endpoint on a trusted network.
Cloud provider
Connects to an explicitly configured OpenAI-compatible HTTPS API.

04 / PRIVACY

A bounded page-context path

Safe and Agent edits stay in your Safari rendering; they do not change the origin website or what other visitors see. Planning may send your request and a bounded, sanitized description of the open page to your chosen provider when page context is enabled.

The snapshot excludes cookies and session tokens, browser storage, scripts, form values, password and payment fields, selected files, query strings, other tabs, and browsing history. Sensitive-value redaction is always on, and page context can be disabled.

Provider credentials are stored in the shared Keychain. Apple Intelligence keeps page context on the device; Codex Bridge, local, and cloud routes send sanitized context only to the endpoint you configure.
